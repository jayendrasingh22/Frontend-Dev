1. Explain the difference between frontend, backend, and full-stack development with suitable real-world examples.



Frontend development:
Frontend is what users actually see and interact with on a website. It includes layout, colors, buttons, menus, etc. Technologies used are HTML, CSS, and JavaScript.
Example: When you visit Amazon, the product page, “Add to Cart” button, and layout design you see — that’s frontend.

Backend development:
Backend runs behind the scenes. It handles the logic, database, authentication, and data processing. Technologies used are Node.js, Python (Django), Java (Spring Boot), etc.
Example: When you log in to your account or check order details, the backend verifies your data and fetches information from the database.

Full-stack development:
A full-stack developer handles both frontend and backend.
Example: A full-stack developer can design the webpage (frontend) and also manage data storage and server logic (backend) for the same project.

3. Describe how a browser requests and displays a web page from a web server.



1. The user types a website URL (like www.google.com) into the browser.
2. The browser converts the domain name into an IP address using DNS.
3. A HTTP/HTTPS request is sent to the web server.

4. The web server processes the request and sends back HTML, CSS, and JS files.
5. The browser receives these files, renders them, and displays the final webpage to the user.

5. Explain what a web server is and give examples of commonly used servers.



A web server is software that delivers web pages to users upon request. It listens for HTTP requests from clients (browsers) and sends responses back.
Common examples:
- Apache HTTP Server
- Microsoft IIS
- Node.js (Express server)
